# 交易卡片中间文本区位置调整设计

## 背景

当前交易卡片在左右两个头像之间展示四类核心信息：

- 钱包名
- 成交金额
- Ticker
- 市值

现状的信息位置与目标不一致。用户要求只调整两个头像之间的文本位置，不改动头像、时间、卡片整体结构与交互行为。

## 目标

仅对 `components/ActivityCard.tsx` 中转账/交易卡片的中间文本区域做重排，使其在视觉上满足：

- 左上：Ticker
- 左下：成交金额
- 右上：钱包名
- 右下：市值

同时保持以下内容不变：

- 左侧 token 头像位置、尺寸、点击与 hover 行为
- 右侧用户头像位置、尺寸
- 时间显示位置与现状一致，继续留在右侧钱包信息区
- 文本颜色语义
- 文本复制、右键打开链接、地址高亮、CA 高亮等现有交互
- 卡片整体宽高与外层网格结构

## 方案

采用“只改网格落位，不改行为”的最小改动方案：

1. 保留现有中间文本区的四个文本节点及其现有逻辑。
2. 维持左右头像所在列与右侧头像区域不变。
3. 仅调整中间文本区的布局映射，让四个已有文本块分别落到新的四个角。
4. 不重写业务数据推导，不改变 `displayWalletLabel`、`displayTokenSymbol`、`displayTradeHeadlineText`、`displayMarketCapText` 的生成方式。

## 组件边界

本次只修改 `components/ActivityCard.tsx` 中 `isTransfer` 分支里两个头像之间的文本排布。

不涉及：

- 数据结构
- API
- store
- 样式 token
- 其他卡片类型（Twitter、普通区块链动态等）

## 布局说明

中间文本区域继续保持两列两行的紧凑布局，但重新映射内容：

- 第一行左列显示 `displayTokenSymbol`
- 第二行左列显示 `displayActionVariantLabel + displayTradeHeadlineText`
- 第一行右列显示 `displayWalletLabel`
- 第二行右列显示 `displayMarketCapText`

右侧用户头像区域继续承载时间展示与合并交易标记，不挪动时间位置。

## 错误处理与兼容性

- 若某一项文本为空，沿用当前组件已有的条件渲染逻辑，不额外新增占位符。
- 长文本继续使用当前的 `truncate` 与 `min-w-0` 约束，避免撑破卡片。
- 市值在转账场景下若展示的是对手方地址，继续沿用当前按钮行为与高亮逻辑。

## 验证

实现后重点验证：

- 交易卡片四项文本是否落在目标象限
- 时间仍在右侧钱包区域
- 复制 CA、复制地址、右键跳转、hover 高亮是否保持可用
- 长钱包名与长 ticker 时是否仍能正确截断
